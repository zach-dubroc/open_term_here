
## Add
```bash
omarchy plugin add https://github.com/zach-dubroc/open_terminal_here.git --enable
~/.config/omarchy/plugins/zach-dubroc.open-terminal-here/install.sh
```

## Remove 

```bash
~/.config/omarchy/plugins/zach-dubroc.open-terminal-here/uninstall.sh
omarchy plugin remove zach-dubroc.open-terminal-here
```

Or, for a manual install: delete
`~/.local/share/nautilus-python/extensions/open-terminal-here.py` and reopen Files.
